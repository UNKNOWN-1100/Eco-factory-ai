1.1 The Way of the Program

The Python programming language

Python is a high-level, interpreted, general-purpose programming language created by Guido van Rossum and first released in 1991. High-level means it reads close to English and hides machine details. Interpreted means an interpreter reads and runs the program one statement at a time. There is no separate compile step that you see.

Interactive modeType at the >>> prompt (the shell). Each line runs immediately. Good for testing small ideas.
Script modeSave the program in a file ending in .py and run the whole file. Used for real programs.

Why Python? Simple syntax, free and open source, runs on Windows/Linux/Mac (portable), huge standard library ("batteries included"), and used in data science, web, automation and AI.

What is a program?

A program is a sequence of instructions that tells the computer how to perform a computation. Almost every program, big or small, is built from five basic kinds of instruction:

InstructionMeaningPython example
Inputget data from keyboard, file, networkname = input()
Outputshow data on screen / save itprint(name)
Mathbasic operationstotal = a + b
Conditionalcheck a condition, choose what to runif marks >= 40:
Repetitiondo something again and againfor i in range(5):

Programming is really breaking a big task into smaller and smaller sub-tasks until each one can be done with these basic instructions. This is the "problem-solving approach".

What is debugging?

Errors in a program are called bugs. The process of finding and removing them is debugging. There are three kinds of errors. very imp!

ErrorWhen caughtWhat it meansExample
Syntax errorbefore the program runsthe code breaks Python's grammar rulesprint("Hi" → missing )

(exception)		while the program runsgrammar is fine, but something impossible happens10 / 0 → ZeroDivisionError
Semantic error

TrapSemantic errors are the hardest to find because there is no error message. The program does exactly what you wrote, not what you meant. In avg = a + b / 2, division happens first, so you get a + (b/2). Correct: avg = (a + b) / 2.

Experimental debugging

Debugging is like being a detective: you see clues (wrong output, error message), form a hypothesis about the cause, change the program, and test again. If the hypothesis was wrong, form a new one.

Debugging habits
  • Start with a small program that works, then grow it a little at a time. Test after each small change.
  • Read the error message from the last line upward. It tells you the error type and the line number.
  • Put print() statements to see the values of variables at each step.
  • Use pythontutor.com to watch your program run step by step.
  • Explain your code line by line to a friend (or a rubber duck!). You will often spot the bug yourself.

Variables

A variable is a name that refers to a value. The assignment statement = creates the variable and binds it to the value. Think of the variable as a label stuck on a value, not a box.

message = "Exam on Monday"
n = 17
pi = 3.14159
n = 20          # n now refers to a new value; 17 is forgotten

Python is dynamically typed: you never declare a type. The same name can later refer to a value of a different type.

Variable names and keywords

Naming rules
  • Can contain letters, digits and underscore _.
  • Must not start with a digit: 2marks ✗, marks2 ✓
  • No spaces or special symbols: my-name ✗, my name ✗, my_name ✓
  • Case-sensitive: Marks and marks are different variables.
  • Must not be a keyword.

Keywords are reserved words that define the language's structure. Python 3 has 35 keywords. See them with import keyword; print(keyword.kwlist):

Good style: choose names that say what the value means. total_marks is much better than t.

Statements and evaluating expressions

StatementAn instruction the interpreter can execute. It does something but has no value. e.g. x = 5, print(x), for, if.
ExpressionA combination of values, variables, operators and function calls that the interpreter evaluates to a value. e.g. x + 2, len("hi"), 42

In the shell, typing an expression shows its value. In a script, an expression alone shows nothing. You must print() it.

Order of operations

When an expression has many operators, Python follows PEMDAS:

  1. Parentheses ( ), highest. Use them to force order or just for clarity.
  2. Exponent **
  3. Multiplication & Division: * / // % (same level)
  4. Addition & Subtraction: + -

Same level → evaluate left to right, except **, which goes right to left.

2 ** 3 ** 2      # 2 ** 9  → 512   (not 64)
-3 ** 2          # -(3**2) → -9    (** binds tighter than unary minus)
2 + 3 * 4 ** 2 // 5 % 3 - 1
#   4**2=16 → 3*16=48 → 48//5=9 → 9%3=0 → 2+0-1 = 1

1.3 Iteration

Iteration means repeating a set of statements. Computers are great at doing boring repeated work without mistakes.

Quick recap: if / elif / else Loops almost always need decisions inside them. Indentation (4 spaces) marks the block. Don't forget the colon : 
if marks >= 90:
    grade = "S"
elif marks >= 40:
    grade = "Pass"
else:
    grade = "Fail"

Assignment

= is assignment, == is comparison. a = 7 makes a refer to 7. a == 7 asks "is a equal to 7?" and gives True/False. Assignment is not symmetric: 7 = a is an error.

Python also allows tuple (multiple) assignment: a, b = 3, 4 and the famous swap a, b = b, a.

Updating variables

count = 0            # initialize first!
count = count + 1    # increment
count += 1           # shorthand; also -=, *=, /=, //=, %=
TrapYou must initialize a variable before updating it. total = total + 5 on a fresh variable gives NameError.

A for loop repeats once for each item in a sequence. Use it when you know how many times or what items to loop over.

The while statement

A while loop repeats as long as its condition is True. Use it when you don't know in advance how many times to repeat.

  1. Evaluate the condition → True or False.
  2. If False, exit the loop, continue with the next statement.
  3. If True, run the body, then go back to step 1.
n = int(input("Enter n: "))
total, i = 0, 1
while i <= n:
    total += i
    i += 1              # the loop variable MUST change
print("Sum =", total)
Trap: infinite loopIf nothing in the body moves the condition toward False, the loop never ends. Forgetting i += 1 above is the classic mistake. Press Ctrl+C to stop it.

The Collatz 3n + 1 sequence

Rule: if n is even, the next term is n/2; if odd, it is 3n + 1. Stop when n becomes 1.

def seq3np1(n):
    """Print the 3n+1 sequence from n, stopping at 1."""
    while n != 1:
        print(n, end=", ")
        if n % 2 == 0:
            n = n // 2
        else:
            n = n * 3 + 1
    print(n, end=".\n")

seq3np1(3)
seq3np1(6)
3, 10, 5, 16, 8, 4, 2, 1.
6, 3, 10, 5, 16, 8, 4, 2, 1.

Why is it famous? Nobody has proved that it reaches 1 for every n (the Collatz conjecture). It shows that we can't always know in advance how many times a while loop will run. That is exactly why while exists.

break and continue

breakExits the loop immediately, skipping the rest of the body and all remaining iterations.
continueSkips the rest of this iteration and jumps to the next one. The loop keeps going.
# add numbers until user enters 0; ignore negatives
total = 0
while True:
    x = int(input("number (0 to stop): "))
    if x == 0:
        break            # leave the loop
    if x < 0:
        continue         # skip negative, ask again
    total += x
print("Total of positives:", total)

The pattern while True: … break is called a middle-test loop. The exit check sits in the middle of the body, not at the top.

Paired data

Data often comes in pairs, like a name and a year. Store each pair as a tuple and keep the tuples in a list. A for loop can unpack each pair directly into two variables.

students = [("Asha", 2006), ("Ravi", 2005), ("Meena", 2007)]
for (name, year) in students:
    print(name, "was born in", year)

Nested loops for nested data

When data is nested (each student has a list of subjects), use a nested loop: the outer loop walks over students, the inner loop over that student's subjects.

students = [
    ("Asha",  ["Maths", "Python", "Physics"]),
    ("Ravi",  ["Python", "Chemistry"]),
    ("Meena", ["Maths", "Python", "Mechanics", "English"]),
]

for (name, subjects) in students:

A function is a named sequence of statements that performs a task. You define it once and call it many times.

    """Return the area of a circle."""   # docstring
    a = 3.14159 * radius ** 2
    return a                       # send the value back to the caller

ParameterThe variable name in the function header (radius). It receives a value.
ArgumentThe actual value you pass when calling (r, 10, 2).

Why use functions?

  • Give a name to a group of statements, so the program is easier to read.
  • Write once, reuse many times. If there is a bug, fix it in one place.
  • Break a long program into small parts you can test one at a time.

Return values

  • return ends the function immediately and sends a value back to where it was called.
  • A function with no return (or a bare return) returns the special value None.
  • A function can have several return statements, but only one runs per call.
  • Functions that return values are called fruitful functions. Those that only do something (like print) are void functions.
def absolute(x):
    if x < 0:
        return -x
    return x

def show_abs(x):
    print(abs(x))        # prints, returns nothing

a = absolute(-7)         # a is 7
b = show_abs(-7)         # prints 7, but b is None!
print(b + 1)             # TypeError: unsupported operand 'NoneType' + 'int'
Trap: print vs returnprint() shows a value on the screen. return hands the value back to the program. If you want to use the result in another calculation, the function must return it. In labs, most bugs of the form "I got None" come from this.

Local variables and flow of execution

Variables created inside a function (including its parameters) are local: they exist only while the function runs and can't be seen outside. When a function is called, the flow jumps into the body, runs it, and comes back to the line after the call.

2.1 Strings

A string is a compound data type: an ordered sequence of characters. We can treat it as one thing, or look at its individual parts.

Working with strings as single things

A string is an object with built-in methods: functions attached to it, called with the dot notation.

ss = "Hello, World!"
print(ss.upper())      # HELLO, WORLD!
print(ss.lower())      # hello, world!
print(ss.swapcase())   # hELLO, wORLD!
print(ss)              # Hello, World!  ← the original is unchanged

Working with the parts of a string (indexing)

The indexing operator [ ] picks one character. Indexes start at 0. Negative indexes count from the end.

P0-6Y1-5T2-4H3-3O4-2N5-1

s = "PYTHON" → s[0] is 'P', s[5] is 'N', s[-1] is 'N', s[-6] is 'P'.

Length

len(s) returns the number of characters. The last index is len(s) - 1, not len(s). So s[len(s)] gives IndexError: string index out of range. Safe options: s[len(s)-1] or simply s[-1].

Traversal and the for loop

Traversal = visiting each character one by one, from start to end.

# way 1: while loop with index
ix = 0
while ix < len(fruit):
    print(fruit[ix])
    ix += 1

# way 2: for loop (cleaner, preferred)
for ch in fruit:
    print(ch)

Use the index version only when you need the position too (or use for i, ch in enumerate(fruit)).

Slices

A slice s[m:n] is a substring from index m up to but not including n. Optional third value is the step: s[m:n:k].

String comparison

== checks equality. < and > compare lexicographically (dictionary order), character by character, using each character's Unicode number.

        ix += 1
    return -1

Tuples are used for grouping data

A tuple is an ordered, immutable sequence of values, written with commas (parentheses are usual but optional). It is perfect for a record: several related values about one thing.

student = ("Asha Rao", "1XX24CS057", 2006, "CSE", 8.9)

print(student[1:3])               # ('1XX24CS057', 2006)  ← slicing gives a tuple
print(len(student))               # 5
empty = ()
single = (10,)                    # the comma makes it a tuple
not_tuple = (10)                  # this is just int 10!
TrapA one-element tuple needs a trailing comma: (10,). And tuples are immutable: student[2] = 2007 → TypeError. To "change" it, build a new tuple: student = student[:2] + (2007,) + student[3:]

Tuple operations: + (join), * (repeat), in, len, indexing, slicing, count(x), index(x), and min/max/sum on numeric tuples.

Tuple assignment

A tuple of variables on the left can be assigned a tuple of values on the right in one step. This is called unpacking.

(name, usn, year, branch, cgpa) = student   # unpack the record
a, b = b, a                                 # swap without temp!
x, y, z = 1, 2                              # ValueError: not enough values to unpack

How the swap works: the whole right side is evaluated first into a tuple (b, a), then it is unpacked into a and b. Number of variables on the left must equal number of values on the right.

Tuples as return values

A function can return only one value, but that value can be a tuple, so a function can effectively return many values.

    a = 3.14159 * r * r
    return (c, a)

2.3 Lists

List values

A list is an ordered, mutable collection of values (called elements or items), written in square brackets. Elements can be of any type, even mixed, and even other lists (nested list).

marks = [78, 91, 66]
names = ["Asha", "Ravi"]
mixed = ["hello", 2.0, 5, [10, 20]]   # 4 elements; the last is a list
empty = []

Accessing elements, length & membership

nums = [17, 123, 87, 34, 66, 8398, 44]
nums[0], nums[-1]        # (17, 44)
nums[9 - 8]              # 123  ← any int expression works as index
nums[1.0]                # TypeError: list indices must be integers
len(mixed)               # 4  ← a nested list counts as ONE element
87 in nums                # True
50 not in nums            # True

List operations and slices

a = [1, 2, 3]
b = [4, 5]
a + b             # [1, 2, 3, 4, 5]  concatenation (new list)
[0] * 4           # [0, 0, 0, 0]     repetition
letters = ["a", "b", "c", "d", "e", "f"]
letters[1:3]      # ['b', 'c']
letters[:4]       # ['a', 'b', 'c', 'd']
letters[::-1]     # reversed copy

Lists are mutable

Unlike strings and tuples, we can change a list's elements in place: by index, or by assigning to a slice.

fruit = ["banana", "apple", "quince"]
fruit[0] = "pear"               # ['pear', 'apple', 'quince']
lst = ["a", "b", "c", "d", "e"]
lst[1:3] = ["x", "y"]          # replace:  ['a','x','y','d','e']
lst[1:3] = []                  # remove:   ['a','d','e']
lst[1:1] = ["b", "c"]          # insert:   ['a','b','c','d','e']

List deletion

a = ["one", "two", "three", "four"]
del a[1]          # ['one', 'three', 'four']
del a[1:]         # ['one']   ← del works with slices too

Objects and references

Every value is an object, and a variable holds a reference to it. Two tests:

== equalityDo they have the same value?
is identityDo they refer to the same object in memory? (check with id())
a = [1, 2, 3]
b = [1, 2, 3]
a == b      # True   same value
a is b      # False  two different list objects

Strings are immutable, so Python may safely let two variables share one string object. For lists, each [ ] creates a new, separate list.

Aliasing

When two variables refer to the same object, they are aliases. Changes made through one alias are seen through the other. careful!!

a = [1, 2, 3]
b = a            # NOT a copy. b is another name for the same list
b[0] = 99
print(a)         # [99, 2, 3]  ← a changed too!
print(a is b)    # True

Picture it: two labels a and b stuck on one list.

Cloning lists

To modify a list but keep the original, make a clone (a copy):

a = [1, 2, 3]
b = a[:]          # slice copy   (also: a.copy()  or  list(a))
b[0] = 99
print(a, b)       # [1, 2, 3] [99, 2, 3]
Trap: shallow copya[:] copies only the outer list. Inner (nested) lists are still shared. For nested lists use import copy; b = copy.deepcopy(a).

Lists and for loops

for x in nums:                      # read each element
    print(x)

xs = [1, 2, 3, 4, 5]
for i in range(len(xs)):           # need the index to CHANGE elements
    xs[i] = xs[i] ** 2            # xs → [1, 4, 9, 16, 25]

for (i, v) in enumerate(["x", "y"]):  # index and value together
    print(i, v)
Trapfor x in xs: x = x * 2 does NOT change the list. x is just a temporary name for each element. Use the index form.

List parameters

Passing a list to a function passes a reference, so the parameter becomes an alias of the caller's list. If the function changes the list, the caller sees the change.

def double_stuff(a_list):
    """Overwrite each element with double its value."""
    for (idx, val) in enumerate(a_list):
        a_list[idx] = 2 * val

things = [2, 5, 9]
double_stuff(things)
print(things)          # [4, 10, 18]

Pure functions and modifiers

ModifierChanges the list passed to it (side effect). Example: double_stuff above.
Pure functionDoes not change its arguments; it builds and returns a new value. No side effects.
def doubled(a_list):           # pure version
    new_list = []
    for value in a_list:
        new_list.append(2 * value)
    return new_list

things = [2, 5, 9]
xs = doubled(things)
print(things, xs)              # [2, 5, 9] [4, 10, 18]

Prefer pure functions. They are easier to test and cause fewer surprises. Use modifiers only when copying would be too slow.

Matrices

A matrix is represented as a list of lists: each inner list is one row. m[row][col] picks an element.

mx = [[1, 2, 3],
      [4, 5, 6],
      [7, 8, 9]]
mx[1]          # [4, 5, 6]  (row 1)
mx[1][2]       # 6

# transpose with nested loops
rows, cols = len(mx), len(mx[0])
t = []
for j in range(cols):
    new_row = []
    for i in range(rows):
        new_row.append(mx[i][j])
    t.append(new_row)
print(t)
[[1, 4, 7], [2, 5, 8], [3, 6, 9]]
Trap: the aliasing matrix 
grid = [[0] * 3] * 3      # looks like a 3x3 grid of zeros...
grid[0][0] = 5
print(grid)               # [[5, 0, 0], [5, 0, 0], [5, 0, 0]]  ← all rows changed!
* 3 repeats the same inner list three times (3 aliases). Build each row separately: grid = []; for i in range(3): grid.append([0] * 3)
